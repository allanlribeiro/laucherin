O Mobile inclui o mesmo APK da TV. Instale o aplicativo do celular, conecte a TV e use **Atualizar a tela inicial**. Para personalizar: **Personalizar → Aparência** ou **Papel de parede**.

O Continuar Assistindo acompanha o acabamento e as cores dos widgets; as artes reais e os modos existentes são preservados. A expansão dos times também tem a tabela do Brasileirão Série A.
